# Contributing

Thanks for contributing to CYORE!

## Development

1. `cargo build` — builds the Rust backend and the extension.
2. `cargo test` — runs the Rust tests.
3. `node --check extension.js` — checks the wrapper syntax.
4. Optional: `vsce package` — builds the `.vsix` package.

## Pull requests

1. Fork the repo, create a new branch.
2. Make your changes.
3. Open a PR with a short description of the change.
