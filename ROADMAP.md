# ROADMAP

Future plans for CYORE.

## Planned features

- [ ] Support for more languages (Ruby, PHP, Java, Kotlin, Swift, ...)
- [ ] A webview panel with clickable extracted strings
- [ ] Plugin system for custom extraction rules
- [ ] Bundled prebuilt binaries (Windows, macOS, Linux)

## Stretch goals

- [ ] AI conversion of entire files (not just the active one)
- [ ] Unit/integration tests in CI (already partially covered)
